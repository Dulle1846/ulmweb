Citizen Registry Checker

Check NationStates citizens for World Assembly membership and "Vibonia" region residency.

To use this, you need a **Google Cloud API Key**, your **Spreadsheet ID**, and the **Sheet's GID**.
**WARNING: Your API Key will be visible in the browser's source code. For production environments, a backend server is highly recommended to protect your API key.**

**Instructions:**

  1. Go to Google Cloud Console, create a project.
  2. Enable "Google Sheets API" in the API Library.
  3. Create an "API Key" under "APIs & Services > Credentials".
  4. Make your Google Sheet publicly readable (Share > "Anyone with the link" > "Viewer").
  5. Find your Spreadsheet ID from its URL: https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/edit
  6. Find your Sheet's GID from its URL (if not the first sheet): .../edit#gid=YOUR_GID (usually 0 for the first sheet).
  7. **Your API Key, Spreadsheet ID, and GID are already configured in the JavaScript code below.**
