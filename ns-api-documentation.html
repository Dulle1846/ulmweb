🌍 NationStates API

Interaktive Dokumentation mit direkten Abfragemöglichkeiten

Wichtig: Die NationStates API erfordert einen benutzerdefinierten User-Agent Header. Bitte gib deinen Kontakt oder App-Namen ein!
Rate Limit: Maximal 1 Anfrage alle 600ms (0.6 Sekunden). Diese Dokumentation respektiert automatisch diese Limits.

🏛️ Nation API

Nation Daten abrufen
https://www.nationstates.net/cgi-bin/api.cgi?nation=[NAME]&q=[SHARDS]

Verfügbare Shards:

name
fullname
type
motto
category
population
region
founded
lastlogin
influence
freedom
gdp
income
currency
demonym
demonym2
demonym2plural
flag
majorindustry
govtpriority
govt
endorsements
census
Wähle eine Nation und klicke auf "Abfragen"...
